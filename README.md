# SMKDMR XLX Client

Android-клиент для подключения к XLX-серверу.

## Сейчас готово

- Базовый Android-проект на Kotlin и Jetpack Compose.
- Первый экран подключения.
- Выбор IP/домена XLX-сервера.
- Выбор порта.
- Выбор комнаты/модуля.
- Простая валидация ввода.

## Следующий этап

1. Добавить модель настроек подключения.
2. Сохранять последний сервер, порт и комнату локально.
3. Реализовать транспортный слой XLX.
4. Добавить экран состояния соединения.
5. Добавить журнал событий подключения.

## Сборка

Откройте проект в Android Studio и выполните сборку модуля `app`.
